      {{ icon('download') }}Backup · download all repositories

      Read-only — nothing on GitHub is ever changed. The site only reads the list of your repositories and branches (its token stays on the server). Two ways to download:

      • Full backup (recommended) — every repository with all branches, tags and the full history. Download the small script for your computer and double-click it (needs Git); it saves everything in GitHub-Backup in your user folder, and running it again later just updates that backup. Private repositories are included when GitHub CLI is installed and signed in (gh auth login) — git then uses your own sign-in. The script contains no passwords or tokens.
      • ZIP of every branch — a snapshot of the files of each branch of your public repositories, straight from github.com (no history). Your browser may ask once to allow multiple downloads.
